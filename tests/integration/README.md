# Integration

From the root, run `npm run build:contracts`, `npm run dev` and `npm run test:integration`. The local suites check RPC readiness, run the Phase 1 sponsored transfer and authorization mutation tests, run the P2 agent registry flow in `agent-flow.test.ts` with real controller, signer, new-signer and sponsor signatures ([results](../../docs/P2_VALIDATION.md)), and run the P3 verification flow in `verification-flow.test.ts` with real admin, provider, fixture-provider, controller and sponsor signatures ([results](../../docs/P3_VALIDATION.md)). The P3 suite serves agent metadata through an in-process transport because a local network cannot reach a public host; identities, signer accounts and publication are real. Policy enforcement arrives in P4. Shared local-network helpers live in `support/`.

The `.planned.ts` files preserve the original scenario notes and are intentionally not discovered as executable tests. Replace them with real `.test.ts` suites as the behavior lands. Empty executable suites fail.
