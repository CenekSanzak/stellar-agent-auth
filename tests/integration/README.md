# Integration

From the root, run `npm run build:contracts`, `npm run dev` and `npm run test:integration`. The local suites check RPC readiness, run the Phase 1 sponsored transfer and authorization mutation tests, run the P2 agent registry flow in `agent-flow.test.ts` with real controller, signer, new-signer and sponsor signatures ([results](../../docs/P2_VALIDATION.md)), and run the P3 verification flow in `verification-flow.test.ts` with real admin, provider, fixture-provider, controller and sponsor signatures ([results](../../docs/P3_VALIDATION.md)). The P3 suite serves agent metadata through an in-process transport because a local network cannot reach a public host; identities, signer accounts and publication are real. The P4 wallet flow in `wallet-flow.test.ts` deploys every contract, issues a test asset, and runs the SOW gate payment, rejections, pre-revocation signed payments, pause, replacement and an on-chain rollback with real owner, funder, agent and sponsor signatures ([results](../../docs/P4_VALIDATION.md)). Shared local-network helpers live in `support/`; `support/wallet-world.ts` sets up the wallet environment for this suite and the adversarial suites.

Empty executable suites fail.
